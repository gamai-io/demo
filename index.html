Reproduce the 25,600-trial run

sbatch --partition=standard --nodes=8 --export=ALL,RUNS=200 sbatch-f2-crossnode.sh
# 25,600 trials | pass 93.75% | false-success 6.25% | 0 on read/action/cross

What each repo proves

  • gamai-trust - verify claims, remember refusals, score false success.
  • sigil - proof-carrying execution profile (grants to receipts to anchor).
  • crossnode-bench - measure agent honesty across heterogeneous nodes.
  • gamai-guard - multilingual prompt-injection guard (29/30 blocked, 0/10 FP).

Honest limits

  • v0.x. The trust layer reports state; it does not make an agent honest.
  • Every repo ships repro.sh - verify it yourself. We publish evidence, not slides.

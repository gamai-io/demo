What each repo proves

  • gamai-trust - verify claims, remember refusals, score false success.
  • sigil - proof-carrying execution profile (grants to receipts to anchor).
  • crossnode-bench - measure agent honesty across heterogeneous nodes.
  • gamai-guard - multilingual prompt-injection guard.

Honest limits

  • v0.x. The trust layer reports state; it does not make an agent honest.
  • Repositories that ship a repro.sh publish one you can run; the rest name the release file and its sha256. We publish evidence, not slides.
  • Every figure on this page is recomputed by render.py from the artifact hashes above; the page cannot drift from them. Figures that are not machine-checked here are not shown, with one exception: the "Validated on EuroHPC LUMI" badge, which is a statement, not a measurement.
  • Correction. The earlier version of this page mixed the honest fleet run with an unpublished Slurm run and quoted its pass rate. Those figures are gone; the honest run above is the shipped fleet run, and its numbers now come straight from honest/evidence.jsonl.gz.
